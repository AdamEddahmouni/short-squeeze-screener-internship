# Phase 2A Progress

Phase 2A is implemented on `phase/2a-foundational-market-metrics` as a local-only, deterministic
derived-metrics layer built exclusively on point-in-time eligible Phase 1H `MARKET_BARS`
evidence.

## Delivered

- `squeeze_core.metrics` as a peer package to `squeeze_core.evidence`: explicitly-typed frozen
  `MetricResult`/`TrailingWindow`/`SampleCounts`/`BarBoundaryRef` models, a deterministic-ID
  scheme under its own UUID namespace, and canonical serialization reused unmodified from
  `serialization.canonical_json`
- point-in-time/lifecycle/provider bar selection (`metrics.selection`) built directly on
  `evidence.bars.build_bar_series` rather than a fourth reimplementation of the point-in-time gate
- `ABSOLUTE_RETURN`/`PERCENTAGE_RETURN` (`close_to_close_completed.v1`)
- `ABSOLUTE_SESSION_GAP`/`PERCENTAGE_SESSION_GAP` (`explicit_prior_close_to_current_open.v1`,
  explicit caller-supplied boundaries, no exchange calendar)
- `ABSOLUTE_BAR_RANGE`/`PERCENTAGE_BAR_RANGE` (`low_denominator_range.v1`)
- `MEAN_VOLUME_BASELINE` (`trailing_mean_exclude_current.v1`), current bar excluded by default,
  zero-volume retained, missing-volume/wrong-unit/conflicted excluded and separately counted
- `build-market-metrics` offline CLI command, local files only, canonical JSON, deterministic
  repeated output, nonzero exit on invalid requests
- 158 new tests across `tests/metrics/` (models, identifiers, diagnostics, selection, returns,
  gaps, ranges, volume baselines, CLI, isolation, compatibility, anchors), covering every required
  case family from the Phase 2A handoff
- a separate Phase 2A anchor manifest (`tests/fixtures/metrics/expected_phase_2a_metric_metadata.json`,
  sixteen anchors, never merged into the Phase 1 manifest) regenerated byte-identically twice
  before committing
- ADRs 0029-0031; `foundational-market-metric-contract.md` and per-metric semantics docs

## Deterministic anchors

Canonical values are stored in
`tests/fixtures/metrics/expected_phase_2a_metric_metadata.json`. All Phase 1 anchors in
`tests/fixtures/compatibility/phase_1_anchor_manifest.json` remain byte-for-byte unchanged.

## Explicit exclusions

There is no relative volume, volume ratio/z-score, dollar volume, turnover, rolling return,
momentum score, rate-of-change, ATR, true range, standard deviation, volatility score, RSI, MACD,
moving average, Bollinger/Keltner channel, TTM Squeeze, breakout/trend/gap classification,
candlestick pattern, order-flow/aggressor-side metric, candidate score/rank/Prime-Subprime,
recommendation, entry/exit/target/stop, backtesting, live/network/database/GUI code, or
machine learning anywhere in `squeeze_core.metrics`.
