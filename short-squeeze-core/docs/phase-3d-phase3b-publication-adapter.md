# Phase 3D Phase 3B Publication Adapter

The adapter validates a curated bundle against an existing Phase 3B registry entry or dataset row and returns that typed object unchanged. It does not extend Phase 3B models or alter serialization.

Incomplete honest attempts may be registry candidates. Dataset publication requires a complete, reviewed, leakage-passing, non-synthetic bundle whose symbol and case ID match the Phase 3B row. Failed leakage, synthetic classification, or incomplete status blocks dataset publication. A dependent secondary boundary remains marked in Phase 3D and does not increase the independent-symbol count.
