# Phase 3C Dependence and Duplicate Symbols

Multiple boundaries for one symbol are dependent observations. The dependence summary retains counts per symbol, repeated-boundary totals, affected symbols, the independence status, and the recommended analysis unit.

BIYA has two historical boundaries but one unique symbol. The case-boundary view therefore has two dependent observations; the primary view selects the earliest concrete BIYA row and has one observation. Neither view supports generalization or predictive validation.
