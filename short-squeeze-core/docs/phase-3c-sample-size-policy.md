# Phase 3C Sample-Size Policy

`phase_3c_sample_size_policy.v1` records the observation count, unique-symbol count, analysis unit, state, allowed interpretation, and forbidden interpretation. States are fixed: 0 `NO_OBSERVATIONS`, 1 `ONE_OBSERVATION`, 2–4 `VERY_SMALL`, 5–19 `SMALL`, 20–49 `LIMITED`, and 50 or more `DESCRIPTIVE_ONLY`.

No threshold claims statistical or predictive validation. Counts never override dependence or provenance restrictions.
