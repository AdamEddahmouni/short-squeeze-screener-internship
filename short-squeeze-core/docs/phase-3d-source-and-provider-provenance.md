# Phase 3D Source and Provider Provenance

Discovery records retain observed symbol, observation time, source class and name, artifact ID, provider and scope, exact query/filter definition, original order, platform-surfaced status, reason, and classification. Manual leads remain distinct from systematic sources. Public evidence never implies that the original platform surfaced a symbol.

Provider provenance keeps event, observed, effective, published, received, and artifact timestamps as separate fields. It also records product, dataset, scope, access method, latency, historical/current state, revision state, and license reference. Missing scope remains missing. A current observation cannot reconstruct a historical value without explicit historical evidence.

Discovery, evaluation, and outcome artifacts use separate manifests. Restricted local artifacts may participate in local review but are not projected into public fixtures or exports.
