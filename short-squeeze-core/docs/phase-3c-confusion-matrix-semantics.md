# Phase 3C Confusion-Matrix Semantics

Cells are deterministic cross-tabulations of Phase 3B research detection and retrospective outcome labels. Unevaluable detection or outcome states remain outside TP/FP/TN/FN and are counted explicitly. Sensitivity, specificity, positive predictive value, and negative predictive value use exact denominators; zero denominators remain undefined.

For historical cohorts these are descriptive research-classification rates, not model accuracy or validated performance. For synthetic cohorts the cells test software truth tables only and receive no historical or empirical interpretation.
