# Phase 3D BIYA and Incomplete-Case Migration

The migration reads the unchanged Phase 3B registry. `BIYA_EARLIEST_BOUNDARY` is the primary historical bundle and `BIYA_LATEST_BOUNDARY` points to it as a dependent secondary boundary. Both preserve prior case IDs, source artifact IDs, classifications, limitations, and Phase 3B objects without reinterpretation.

KLRS, LBGJ, SG, TRVI, and SLS remain partial because no defensible complete detection snapshot survives. KLOS remains blocked by conflicting identity. All remain registry-visible. The migration adds no new complete historical case and does not claim that prior evidence was collected under the new preregistered plan.
