# Phase 3D Case Curation Workflow

Bundles advance monotonically from discovery through artifact capture, normalization, identity and eligibility review, boundary freeze, evaluation freeze, outcome capture, research evaluation, review, and publication. Partial, blocked, excluded, rejected, and superseded terminal review states preserve honest incompleteness. Invalid jumps fail.

The acquisition ledger is append-only. Reprocessing an identical attempt is idempotent; reusing its ID for different semantic content fails. Input records are canonically ordered so resume and reversed manifest order produce identical bytes.

One resolved security identity is the default empirical unit. The earliest eligible outcome-blind boundary is primary; later boundaries may remain as explicitly dependent secondary observations.
